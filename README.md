# `Nexora` 

> **给终端用户的安全承诺**：`Nexora` 客户端专为安全、私密的异地组网而设计。您的所有数据传输均经过**端到端强加密**，客户端私钥支持**本地硬件芯片保护**，彻底保障您的设备安全与个人隐私。

## 1. 🔒 端到端加密：只有接收方能解密

* **点对点传输 (P2P)**：客户端之间优先建立 P2P 直连隧道，数据直接在设备间点对点传输。
* **零中转泄露**：即使在极端网络下需要中转，数据在离开您的客户端前就已经完成了高强度加密。**中转服务器只能帮忙转发加密数据包，绝对无法解密或查看您的实际传输内容。**
* **一会一密 (前向安全性)**：每次连接都会自动生成一次性加密密钥，保证数据即使在未来也无法被反向破译。

---

## 2. 🔑 硬件级密钥保护：不怕凭据被偷

* **支持 TPM 2.0 硬件芯片锁**：客户端支持将您的身份私钥直接锁入电脑本地的 TPM 2.0 安全芯片（支持 Windows CNG 与 Linux TPM2）。
* **私钥不可导出**：即便您的电脑不慎感染了普通木马或恶意软件，攻击者也**无法导出或盗走**存储在硬件芯片中的客户端身份凭据。

---

## 3. 🛡️ 客户端安全隔离：保护本机不受入侵

* **虚拟网卡安全防护**：客户端创建的虚拟网卡（TUN）具备独立的访问控制策略。
* **防横向渗透**：当您连接公共出口网关或加入共享组网时，客户端会自动拦截未授权的反向主动连接请求，确保组网内的其他设备无法非法访问您本机的私有文件或服务。

---

## 4. 🌐 公共 Wi-Fi 安全防护

* **公共网络安全屏障**：在机场、酒店或咖啡厅连接不可信的公共 Wi-Fi 时，开启客户端的全局防护模式，所有上网流量都会经过高强度加密隧道传输。
* **防抓包与篡改**：有效抵御同一局域网内的 ARP 欺骗、DNS 劫持和中间人抓包窃听。

## 5. ⚡ 内存安全与零隐私采集

* **Rust 语言底层安全**：客户端全量采用 Rust 语言编写，从源头杜绝了缓冲区溢出、野指针和崩溃漏洞，运行极度稳定轻量。
* **零个人隐私采集**：客户端仅在本地内存中处理组网必要的网络路由信息，**绝对不会搜集、记录或上传**您的任何浏览记录、文件内容或个人隐私数据。

## 1. 🏠 个人与家庭场景

### 场景一：无公网 IP 远程访问家中 NAS / 私有云
* **痛点**：家里装了群晖、威联通、Unraid 或绿联 NAS，但家里的宽带没有公网 IPv4，在公司或外面无法访问；传统内网穿透（如花生壳）速度慢、限制多且要按流量收费。
* **解决方案**：NAS 运行客户端，手机/笔记本也安装客户端。通过专有的虚拟 IP（如 `100.64.0.5`）秒连家中 NAS。两端通过 **P2P 直连**，传输速度直接跑满家里的百兆/千兆上行宽带，流畅播放 4K 视频。

### 场景二：远程开机 + 远程桌面操控 (WoL + RDP/SSH)
* **痛点**：出差在外急需家里台式机上的文件，但电脑处于关机状态；把电脑一直开着又浪费电。
* **解决方案**：结合程序内置的 **Wake-on-LAN (WoL) 远程唤醒** 功能，借由家中常开的软路由或 NAS，远程广播发包唤醒关机的电脑，再通过微软 RDP 或 SSH 登录操控，实现“即用即开，用完关机”。

## 2. 🏢 远程办公与企业 IT 场景

### 场景三：异地办公与安全访问公司内网系统
* **痛点**：员工在家办公或出差，需要访问公司内网的 Gitlab 代码库、Jira、OA 系统或测试数据库。搭建传统 OpenVPN/IPsec 部署复杂、运维成本高，且所有流量集中在公司出口导致网速慢。
* **解决方案**：公司内网服务器部署客户端，员工一键接入。由于节点间优先建立 P2P 直连，员工访问机房速度极快，且不占用公网 VPS 的中转带宽。

### 场景四：局域网设备全量共享 (子网路由宣告)
* **痛点**：办公室里有网络打印机、IP 摄像头、NAS 或嵌入式硬件，这些设备**本身无法安装任何软件**。
* **解决方案**：在办公室的某台 Linux/Windows 电脑上开启 **子网宣告 (`subnet_routes = ["192.168.1.0/24"]`)**。外地员工开启“接受子网路由”后，无需在打印机上做任何改动，就能在千里之外直接使用办公室的打印机或访问摄像头。

### 场景五：多分支机构与多部门权限隔离 (Group Isolation)
* **痛点**：公司在上海、北京、深圳都有分公司，且财务部、研发部与外包团队需要严格的网络访问隔离。
* **解决方案**：利用内置的 `groups` 组隔离机制，同一台中心服务器下可以划分为 `office-shanghai`、`finance` 等独立分组。财务网络与研发网络完全隔离，防止跨部门非法横向访问。

## 3. 💻 跨地域联机与极客玩法

### 场景六：游戏私服与局域网联机 (P2P Gaming)
* **痛点**：和朋友一起玩《幻兽帕鲁》、《Minecraft》、《星露谷物语》等游戏，本地建房联机时因为处于不同运营商（如电信和移动）导致延迟极高或无法连通。
* **解决方案**：所有好友加入同一个组网后，游戏直接识别为“本地局域网（LAN）联机”，不仅延迟极低，而且免去了公网端口映射的繁琐设置。

### 场景七：多云 / 多机房服务器安全互联
* **痛点**：企业业务分布在阿里云、腾讯云、AWS 以及自建机房，跨云服务器之间通过公网通信暴露端口，极易遭受攻击。
* **解决方案**：将分布在不同云厂商的服务器加入专有组网，全部关闭公网敏感端口，仅通过加密组网 IP 进行内网交互与数据同步。

## 4. 🛡️ 网络安全与网络接管场景

### 场景八：公共 Wi-Fi 下的加密通信 (全局出口网关)
* **痛点**：在机场、酒店、咖啡厅使用公共 Wi-Fi，担心数据被同一局域网的黑客抓包监听。
* **解决方案**：指定家中或机房的一台优质节点作为 **Exit Node (出口网关)**。在公共 Wi-Fi 下开启客户端的“全局路由模式”，所有上网流量都会被加密送至出口节点代发，有效防御 ARP 欺骗与数据包监听。

### 场景九：Windows 热点共享组网 (Hotspot Sharing)
* **痛点**：手头只有一台 Windows 笔记本连上了组网，但旁边的手机、iPad 或树莓派也想访问组网内的资源，又不想在每台设备上都装软件。
* **解决方案**：开启 Windows 客户端的全局网关接管并开启“Windows 移动热点”。手机连上该笔记本的热点后，自动共享组网能力，直接访问组网资源。
